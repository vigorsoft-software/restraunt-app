# **App Name**: Culinaro

## Core Features:

- Artisanal Menu Showcase: A high-performance visual grid of dishes with immersive product images and category filtering.
- Streamlined Cart System: An intuitive side-drawer shopping cart for managing selections without leaving the menu.
- Fast COD Checkout: A simplified checkout flow collecting only name and mobile number for seamless Cash on Delivery orders, persisted via a database.
- AI Flavor Writer Tool: An admin tool that uses reasoning to generate appetizing dish descriptions from a list of raw ingredients.
- Admin Inventory Console: A secure dashboard for managing products, images, and prices in real-time.
- Mobile-Optimized Order Flow: A touch-first design specifically tailored for high conversion rates on mobile devices.

## Style Guidelines:

- Primary Color: Vibrant Clay (#F28C3D) to evoke warmth and artisanal quality.
- Background Color: Deep Umber (#140E0A), providing a sophisticated, dark-mode canvas that makes food photography pop.
- Accent Color: Soft Coral (#DE6E74) for subtle call-to-actions and status indicators.
- Font Pairing: 'Playfair' (Serif) for headlines to create an upscale editorial feel, and 'PT Sans' (Sans-serif) for readable body text.
- Immersive asymmetrical grid layout inspired by high-end gastronomy lookbooks.
- Buttery smooth layout transitions and image reveal effects using Framer Motion.
- Minimalist, thin-stroke custom line icons for navigational elements like the cart and user profile.
